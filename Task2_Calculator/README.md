# Task 2 - Calculator

A simple command-line calculator application developed as part of the CodSoft Python Programming Internship.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero error handling
- Invalid input handling
- User-friendly command-line interface

## How It Works

The program asks the user to enter:

1. First number
2. Second number
3. Operation choice

The calculator then performs the selected arithmetic operation and displays the result.

## Supported Operations

| Choice | Operation |
|--------|-----------|
| 1 | Addition |
| 2 | Subtraction |
| 3 | Multiplication |
| 4 | Division |

## Error Handling

The calculator handles:

- Non-numeric input
- Invalid operation choices
- Division by zero

## Technologies Used

- Python
- Command Line Interface (CLI)

## How to Run

Make sure Python is installed on your computer.

Run the following command:

```bash
python calculator.py
