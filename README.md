# To-Do List Application

A simple command-line To-Do List application built using Python.

## Project Description

This project is a Python-based To-Do List application that allows users to manage their tasks through a simple menu-driven interface.

Users can add, view, update, delete, and mark tasks as completed.

## Features

* Add new tasks
* View all tasks
* Update existing tasks
* Delete tasks
* Mark tasks as completed
* Display task status
* Handle empty task input
* Handle invalid menu choices
* Handle invalid task numbers
* Simple command-line interface

## Technologies Used

* Python
* Python Lists
* Python Dictionaries
* `while` loop
* `if-elif-else`
* `input()`
* Functions such as `append()` and `pop()`
* Exception handling with `try-except`

## How to Run

1. Make sure Python is installed on your computer.
2. Open the `Task1_ToDo_List` folder in VS Code or a terminal.
3. Run the following command:

```bash
python todo.py
```

## How to Use

After running the program, the main menu will appear:

```text
===== MAIN MENU =====
1. Add Task
2. View Tasks
3. Update Task
4. Delete Task
5. Mark Task Complete
6. Exit
```

Enter the number corresponding to the operation you want to perform.

### Add Task

Select option `1` and enter the task you want to add.

### View Tasks

Select option `2` to display all available tasks and their current status.

### Update Task

Select option `3`, enter the task number, and provide the new task name.

### Delete Task

Select option `4` and enter the task number you want to delete.

### Mark Task Complete

Select option `5` and enter the task number to mark it as completed.

### Exit

Select option `6` to close the application.
